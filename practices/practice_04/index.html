Олимпиадная математика с нуля

Для школьников 5–9 классов, которые ещё ни разу не участвовали в олимпиадах. Учимся решать нестандартные задачи спокойно и в небольших группах.

Выбрать программу Как проходят занятия

Почему здесь легко начать

  • Начинаем с самых основ

    Первые занятия о том, как читать условие, пробовать разные идеи и не бояться ошибиться.

  • Небольшие группы

    Тренер успевает выслушать решение каждого и разобрать его вместе с группой.

  • Задачи по уровню

    Входной тест помогает подобрать группу, где задачи посильные, но не скучные.

Для кого

  • Ученики 5–9 классов.
  • Школьная математика даётся без особого труда.
  • Опыт олимпиад не нужен: начнём с первой задачи.

Частые вопросы

Нужен ли опыт олимпиад?

Нет. Программы рассчитаны на тех, кто только начинает. Достаточно уверенно чувствовать себя со школьной математикой.

Как выбрать программу?

По классу: 5–6 класс выбирают «Старт», 7–8 класс «Основу», 9 класс «Интенсив». Входной тест поможет уточнить уровень.

Зачем нужен входной тест?

Это не экзамен. Несколько коротких задач помогают тренеру понять, с чего лучше начать.

Сколько стоит пробное занятие?

Пробное занятие бесплатное. Дальше оплата помесячная, по цене выбранной программы.
