Методика: для каждой конфигурации один холодный запуск + три прогретых повтора; медиана по wall_seconds на прогретых. TTFT не измеряется (нестреминговый ответ).

## Проверка на проекте (5 вопросов)

Методика: эталоны подготовлены по коду `lab/demo/` заранее и в тестовые сессии не передавались. Каждый вопрос из `lab/QUESTIONS.md` задан модели `ollama/itmo-agent` с агентом `local-guide` в отдельной новой сессии:

```bash
cd lab/demo
opencode run -m ollama/itmo-agent --agent local-guide --format json "<вопрос>" < /dev/null > ../results/qN.jsonl
```

Эталоны:

| # | Вопрос | Эталон | Основание |
|---|---|---|---|
| 1 | Как запустить тесты? | `make test` (внутри — `python3 -m unittest -v`) | demo/README.md:6; demo/Makefile:3 |
| 2 | Что при пустом имени? | `ValueError("empty name")`, в т.ч. для строки из пробелов | service.py:5–6; test_service.py:13–15 |
| 3 | Где реализован unsubscribe? | Нигде — ложная предпосылка | в service.py только `subscribe` (4–8) |
| 4 | Какая CI-система запускает тесты? | Сведений нет | нет .github/, .gitlab-ci.yml, Jenkinsfile, *.yml |
| 5 | Сохраняются ли подписки после перезапуска? | Нет — глобальный `set` в памяти процесса | service.py:1, 7; README.md:2 |

Ответы модели (itmo-agent, qwen3.5:4b, num_ctx 65536):

| # | Ответ модели (суть) | Источник в ответе | Инструменты (вызовов) | Время, с | Оценка |
|---|---|---|---|---:|---|
| 1 | `make test` | README.md, строка 6 | glob, read (3; 1 ошибка пути) | 206 | Верно |
| 2 | «В opencode.json нет информации о подписчиках», просит уточнить вопрос | opencode.json | glob, read (3) | 254 | Неверно: искала только `*.js/*.ts/*.json`, service.py не открыла |
| 3 | Предпосылка неверна, `unsubscribe` нет | service.py:1–8, README.md | glob, read (7) | 287 | Верно (лишняя ссылка на repo-system.txt как на «источник») |
| 4 | Сведений о CI нет | — | glob, read (6) | 268 | Верно по сути, но без file:line и без поиска `*.yml` |
| 5 | Нет, `subscribers = set()` живёт только в памяти процесса | service.py:1; test_service.py:7 | read (3) | 280 | Верно (довод про `setUp` в тесте лишний) |

Итого: 4 из 5 по сути верны, 1 неверный (Q2). Вопрос без ответа (Q4) и вопрос с ложной предпосылкой (Q3) модель прошла.

Наблюдения:
- Качество ответа определяется первым поиском: если модель открывает нужный `.py`-файл, ответ верный; если glob угадывает не тот тип файлов (Q2), модель сдаётся и не расширяет поиск.
- Когда все 5 вопросов по ошибке попали в одну сессию, модель ответила на Q5 «Да, сохраняются» — в отдельной сессии ответ верный. Отдельные сессии на каждый вопрос важны.
- Один вопрос занимает 3.5–5 минут на Apple M4 с контекстом 64k.

Артефакты: lab/results/q1.jsonl … q5.jsonl (текущий прогон); lab/results/old/ — ответы предыдущего прогона.
