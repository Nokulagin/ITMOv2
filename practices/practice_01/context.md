## Context Pack для первого рабочего сценария

### Факты и правила

- Доступен POST `/api/reviews`, который принимает JSON с ключом `diff` и возвращает `{"comment": str}`.
- Вход не валидируется Pydantic-схемой; используется сырой `dict` и прямой доступ по ключу.
- Вызов LLM синхронный через `llm.generate(prompt)` без обработки исключений.
- Формирование промпта: префикс "Review this pull request and find problems:" + сырой diff.

### Формат входа и результата

- Вход: JSON `{ "diff": string }`.
- Результат: JSON `{ "comment": string }`.

### Ограничения и запрещённые действия

- Нельзя полагаться на внешние файлы/данные вне TRAINING_PR.diff и текущих .md.
- Нельзя изменять файлы, кроме problem.md, prompts.md, context.md.
- Не делать выводы, не подтверждённые диффом.

### Хороший пример

- «app/api.py:35-37 — нет валидации входа; при отсутствии ключа `diff` будет KeyError и 500» с ссылкой на строки.
### Плохой пример

- «Нужно сделать красивый UI для ревью» — это вне контекста и не подтверждено диффом.
### Что пока неизвестно

- Требуются ли аутентификация/авторизация для `/api/reviews`.
- Целевая версия Python и лимиты LLM (токены, таймауты).
- Требуемая структура ответа помимо поля `comment`.

## Как использовали AI

- Для чего: формализация контекста, ограничений и артефактов для сценария ревью.
- Тип промпта: zero-shot и master prompt.
- Строка в [`prompts.md`](prompts.md): P1-01, P1-02.
- Что проверили и исправили сами: соответствие выводов кодовым строкам, явное разделение фактов и допущений.
