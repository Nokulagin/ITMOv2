# Feature C (signup-backend): проверка в браузере

Дата: 2026-10-16. Chromium через Playwright MCP, сервер `python3 server/app.py --port 8765 --db <scratchpad>/signups.sqlite3`
(тестовая база вне репозитория). Тестовые данные: «Анна», anna@example.ru. `prefers-reduced-motion: reduce`.

| Задача | Сценарий | Результат |
|---|---|---|
| 4.1 | Мышью: Основа, 7 класс, 3 месяца → отправка | Сводка «Основа» / «3 месяца» / «16 815 ₽», фокус на заголовке сводки, строка в SQLite |
| 4.1 | Клавиатурой: «Выбрать» (Старт) + Enter → Tab по полям → Enter дважды в email | Ровно 1 POST, сводка «Старт» / «6 месяцев» / «26 460 ₽», фокус на заголовке; ошибок JS нет |
| 4.2 | `page.route`: 400 `errors.email` | Текст в `#signup-email-error`, `aria-invalid="true"`, фокус на email, кнопка активна |
| 4.2 | `page.route`: 400 `program` + `suggested_program: base` (класс 7) | «Для 7 класса подходит «Основа».» + кнопка «Выбрать «Основу»»; нажатие → Основа, 5900 ₽ |
| 4.2 | `page.route`: 400 только `errors.months` | Общая ошибка, значения формы на месте |
| 4.3 | Сервер остановлен (`pkill`), отправка | «Не удалось отправить заявку. Попробуйте ещё раз.» как `role="alert"` вне `aria-live`, фокус на кнопке, кнопка активна, значения на месте |
| 4.3 | Сервер снова запущен, повторная отправка с той же страницы | 201 → сводка, общая ошибка исчезла |
| 4.3 | `page.route` без ответа (зависание) | Общая ошибка через 10,05 с; во время ожидания `aria-disabled="true"`, после — снято |
| 4.3 | Пустая форма → отправка | 0 запросов к `/api/signup`, фокус на первом поле с ошибкой |
| 4.4 | 360 / 768 / 1280 px | Нет горизонтальной прокрутки; 14 якорей, битых нет; «Выбрать» выбирает свою программу и прокручивает к `#signup`; «—» и «Выберите программу» до выбора; 6 мес. Интенсив = 37 260 ₽; Tab: программа → класс → срок → имя → email → согласие → кнопка; кнопка «Выбрать «Основу»» работает с клавиатуры |

Консоль: ошибок скрипта (`pageerror`) нет. Chromium сам пишет в консоль «Failed to load resource» на ответы 400
из подмен и на `ERR_CONNECTION_REFUSED` при остановленном сервере: это сетевые записи браузера об ожидаемых ответах.
