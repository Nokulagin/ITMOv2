## Phase 7: HTTP API (`app.py`)

**Purpose**: маршрутизация и ошибки по контракту, разделы 3–4.

- [ ] T015 Реализовать `app.py`: `http.server.HTTPServer` (не `ThreadingHTTPServer`, см. `plan.md` → Research), маршруты `GET`, `POST`, `PATCH`, `DELETE` на `/api/todos` и `/api/todos/{id}`. Неизвестный путь → `404` «Маршрут не найден.», неподдерживаемый метод → `405` «Метод не поддерживается.»
- [ ] T016 Реализовать в `app.py` разбор тела: сначала проверка `Content-Length` и лимит 4096 байт → `413` «Тело запроса слишком большое.» до разбора JSON; затем `json.loads`, не объект → `400`
- [ ] T017 Реализовать в `app.py` сопоставление исключений с кодами: `ValidationError` → `400` с текстом, `NotFound` → `404` «Задача не найдена.», `sqlite3.Error` → `500` «Внутренняя ошибка сервера.» (детали в журнал сервера, клиенту не отдаются)
- [ ] T018 Реализовать в `app.py` разбор аргументов `--port` (по умолчанию 8000), `--db` (по умолчанию `data/todos.db`). Слушать `127.0.0.1`
- [ ] T019 Написать `tests/test_app.py`: сервер на свободном порту с временной базой. Проверить: `201`, `200`, `204`, `400` (тесты 11, 16, 17), `404` (тесты 18, 19 — нечисловой `id`), `405`, `413` (тест 12, база не меняется), формат `{"error": "..."}`

**Решение, принятое в этом плане**: ответы сервера сериализуются с `ensure_ascii=False`, чтобы русский текст читался. Лимит 4096 байт проверяется по сырому телу запроса, а не по ответу.
