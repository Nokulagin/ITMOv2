## Summary

Бэкенд todo-list: HTTP-сервер на стандартной библиотеке отдаёт четыре операции над задачами
(`GET`, `POST`, `PATCH`, `DELETE` под `/api/todos`) и раздаёт страницу из `static/` (`GET /`,
`GET /static/{имя}`). Задачи хранятся в SQLite-файле `data/todos.db`. Правила валидации, формат ошибок
и правила раздачи статики заданы в контракте. Подход: хранение отдельно от HTTP-обработчика, валидация
отдельно от хранения, раздача статики отдельно от API, тесты `unittest` на каждом слое.

## Technical Context

**Language/Version**: Python 3 (целевая 3.9+, так как документация сверена с 3.9)

**Primary Dependencies**: нет. Только стандартная библиотека: `http.server`, `sqlite3`, `json`,
`argparse`, `mimetypes`, `pathlib`, `contextlib`, `logging`, `unittest`. Пакеты через pip не ставим
(`AGENTS.md`, конституция).

**Storage**: SQLite-файл `data/todos.db` (путь по умолчанию от корня проекта, флаг `--db`).
Папка и таблица создаются при старте.

**Testing**: `unittest` из стандартной библиотеки (конституция, принцип V). Запуск:
`python3 -m unittest discover -s server/tests -t . -v`.

**Target Platform**: локальный запуск на macOS/Linux, один процесс, один клиент, слушает `127.0.0.1`.

**Project Type**: web-service: JSON API и раздача статической страницы на одном origin.

**Performance Goals**: не задаются. Учебный проект, один клиент, однопоточный сервер
(решение из Clarifications).

**Constraints**: только стандартная библиотека; тело запроса не больше 4096 байт; запрос с телом
обязан содержать `Content-Length` (иначе 411); один запрос за раз.

**Scale/Scope**: одна таблица, один список, четыре операции, одна страница. Пагинации нет.

### Source Code (repository root)

```text
server/
├── __init__.py
├── app.py            # точка входа (флаги --port, --db), HTTP-обработчик: маршруты API, тело, ошибки
├── storage.py        # SQLite: соединение с явным закрытием, схема, четыре операции над таблицей
├── validation.py     # правила названия и поля done: обрезка, длина, типы
├── static.py         # раздача static/: GET /, GET /static/{имя}, MIME, защита от выхода за static/
└── tests/
    ├── __init__.py
    ├── test_validation.py   # правила без базы и без HTTP
    ├── test_storage.py      # операции над временной базой
    ├── test_static.py       # раздача: /, файл, нет файла, `..`, MIME
    └── test_api.py          # HTTP: коды 201/200/204/400/404/405/411/413, порядок проверок

static/               # владелец UI: index.html, styles.css, app.js. Логика только раздаёт, не создаёт
data/                 # создаётся при старте; todos.db внутри; в git не попадает (задача .gitignore)
```

**Structure Decision**: модули в `server/`, отдельный `static.py`, чтобы `app.py` не разрастался.
Путь к базе и к `static/` вычисляется от корня проекта (от расположения пакета `server/`), а не от
текущей папки запуска. Порт 8000 и путь к базе задаются флагами `--port` и `--db`.
