# Quickstart: проверка UI списка задач

**Feature**: `specs/001-todo-list/ui/spec.md` | **Plan**: `plan.md` | **Date**: 2026-10-20

Ручная проверка UI по сценариям спецификации. Автоматических UI-тестов в проекте нет (конституция, принцип V).

## Prerequisites

- Запуск из корня `todo-list/`: `python3 -m server.app` (контракт, раздел 10). Страница: `http://127.0.0.1:8000/`.
- Для проверки на другом порту или с отдельной базой: `python3 -m server.app --port 8001 --db <путь>`. Тестовые данные не должны попадать в `data/todos.db`.
- Браузер с возможностью менять размер окна и открывать инструменты разработчика.
- Автотесты логики: `python3 -m unittest discover -s server/tests -t . -v` (к UI не относятся).

## Checks

### 1. Загрузка

1. Откройте страницу.
2. Ожидаемо: сначала «Загрузка…», затем список (или «Задач пока нет. Добавьте первую.»).
3. Остановите сервер и перезагрузите: «Нет связи с сервером. Проверьте подключение и попробуйте ещё раз.» (сетевой сбой, контракт раздел 5). Ответ `500` от сервера даёт «Не удалось загрузить список. Обновите страницу.».

### 2. Добавление

1. Введите «Купить молоко», нажмите Enter.
2. Ожидаемо: задача в начале списка, поле очищено, фокус в поле, счётчик «Выполнено: 0 из 1».
3. Оставьте поле пустым, нажмите «Добавить»: «Введите название задачи.».
4. Введите 201 символ: «Название не длиннее 200 символов.».
5. Быстро нажмите «Добавить» два раза: создаётся одна задача, кнопка на время запроса заблокирована.
6. Проверьте граничные значения по правилу длины, выбранному человеком (см. `plan.md`, «Открытые решения»).

### 3. Отметка

1. Поставьте отметку: название зачёркнуто, счётчик вырос на 1.
2. Снимите отметку: зачёркивание убрано, счётчик уменьшился.
3. Перезагрузите страницу: состояние сохранилось.

### 4. Удаление

1. Нажмите «Удалить»: задача исчезает сразу, без подтверждения.
2. Удалите последнюю задачу: показано пустое состояние, счётчик скрыт.

### 5. Клавиатура

1. Нажимайте Tab от начала страницы до конца: поле → «Добавить» → отметка → «Удалить» → и далее по списку. Ни один элемент не пропущен.
2. Space ставит и снимает отметку; Enter и Space на «Удалить» удаляют задачу.
3. Фокус виден на каждом элементе.

### 6. Адаптивность

1. Откройте страницу при 360, 768 и 1280 px.
2. Горизонтальной прокрутки нет.
3. Длинное название переносится, «Удалить» остаётся в экране.

### 7. Доступность и контраст

1. Экранный диктор читает подпись поля, название задачи и скрытую подпись «Удалить задачу «…»».
2. Контраст текста и рамки фокуса проверен инструментом, не ниже WCAG AA.

### 8. Тексты

Все тексты на экране совпадают с разделом «Тексты интерфейса» спецификации (после утверждения человеком).

## Expected outcome

Все пункты пройдены. Любое отступление фиксируется как расхождение со спецификацией, а не правится в тесте.
