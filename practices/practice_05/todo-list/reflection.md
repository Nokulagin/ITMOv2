# Рефликсия

В процессе выполнения дз сначала создал спеки с двумя сессиями: ui и логика. Потом в главной сессии связал две спеки котрактом и после агенты выполнили задачу с последующей проверкой. Главное что понял - для агента очень важно задать план работы, цель и ограничения. Это не обязательно может быть полное sdd, но с более подробными инстуркциями и знаниями о проекте, результат работы ллм заметно лучше.
