## 2. Матрица статусов по контракту

Сервер поднят командой `python3 -m server.app --port 8765 --db <временная база>`.
База лежит в рабочей папке сессии, вне `data/` проекта. Запросы выполнены `curl`.

| Запрос | Ожидание по контракту | Получено |
|---|---|---|
| `GET /` | 200 | 200 |
| `GET /static/app.js` | 200 | 200 |
| `GET /static/nope.js` | 404 | 404 |
| `GET /static/../server/app.py` (без нормализации пути) | 404 | 404 |
| `GET /api/todos` на пустой базе | 200 | 200 |
| `POST /api/todos` с `"Купить молоко"` | 201 | 201 |
| `POST /api/todos` с пробелами | 400 | 400 |
| `POST /api/todos` с 201 символом | 400 | 400 |
| `POST /api/todos` с `Transfer-Encoding: chunked` | 411 | 411 |
| `POST /api/todos` с телом больше 4096 байт | 413 | 413 |

## 3. Что не проверено в этой записи

- Браузер (клавиатура, фокус, адаптивность, консоль). Агенты делали эти проверки при реализации, но их результаты в репозиторий не сохранялись. Эта запись их не повторяет.
- Экранный диктор (VoiceOver, NVDA). Не проверялся.
- Двойной клик по флажку не блокируется. Спекой это не требуется.
