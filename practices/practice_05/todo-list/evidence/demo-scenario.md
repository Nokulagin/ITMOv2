# Сценарий короткого демо (3–5 минут)

Цель: показать, что интерфейс и сервер работают по контракту 1.1, и объяснить, как процесс привёл к коду.

## Подготовка (до демо)

1. Из корня проекта: `python3 -m server.app`. Сервер слушает `http://127.0.0.1:8000`.
2. Открыть страницу в браузере. Список пустой, счётчик скрыт.
3. Открыть терминал с командой тестов: `python3 -m unittest discover -s server/tests -t . -v`.

## Ход демо

| Время | Что делаем | Что показываем |
|---|---|---|
| 0:00–0:30 | Открываем страницу | Пустой список и текст «Задач пока нет. Добавьте первую.» |
| 0:30–1:15 | Вводим «   » и нажимаем «Добавить» | Сообщение «Введите название задачи.», запроса нет |
| 1:15–2:00 | Добавляем «Купить молоко» и «Позвонить маме» | Новые задачи сверху, поле очищено, фокус в поле |
| 2:00–2:30 | Ставим и снимаем отметку у «Купить молоко» | Зачёркивание, фокус остаётся на флажке |
| 2:30–3:00 | Удаляем «Позвонить маме» | Строка исчезает, счётчик обновлён |
| 3:00–3:30 | Перезапускаем сервер и обновляем страницу | Задача «Купить молоко» осталась: данные лежат в `data/todos.db` |
| 3:30–4:30 | В терминале: `curl -i -X POST -H 'Content-Type: application/json' -d '{"title":""}' http://127.0.0.1:8000/api/todos` | Ответ 400 с текстом «Название задачи не может быть пустым.» |
| 4:30–5:00 | Запускаем тесты | `Ran 74 tests … OK` |

## Что сказать (по одной фразе на шаг)

- Контракт 1.1 согласован до кода: по нему работают и страница, и сервер.
- Сообщения интерфейса на русском; сервер отдаёт коды ошибок, а UI выбирает свой текст по коду.
- Список показывает новые задачи сверху, длина названия считается в кодовых точках Unicode.
- Тесты покрывают контракт; полная матрица статусов записана в `evidence/checks.md`.

## Что не показываем

- Экранный диктор: не проверен, поэтому не заявляем.
- Двойной клик по флажку: спекой не требуется, поэтому не демонстрируем как проблему.

## Если что-то не работает

- Страница не открывается: проверьте, что сервер запущен из корня проекта, а не из папки `static/`.
- Порт 8000 занят: `python3 -m server.app --port 8001` и откройте `http://127.0.0.1:8001`.
